2. 物理屏蔽与存根架构 (Stub Protection)
为了防止 AI 自动全局检索真实文件，必须屏蔽真身，暴露存根。

② 自动生成代码存根 (stub_generator.py)
使用 Python 的 ast（抽象语法树）解析代码，剥离所有具体实现细节，只保留类名、函数签名、参数类型和 Docstring。

Python
# tools/stub_generator.py
import ast
import os
import sys

def generate_stub(source_code: str) -> str:
    """提取 Python 代码的结构存根，过滤所有函数体与具体实现"""
    tree = ast.parse(source_code)
    stub_lines = []

    for node in tree.body:
        if isinstance(node, (ast.FunctionDef, ast.ClassDef)):
            # 仅保留定义头和文档字符串/pass
            if isinstance(node, ast.FunctionDef):
                args = ast.unparse(node.args)
                returns = f" -> {ast.unparse(node.returns)}" if node.returns else ""
                stub_lines.append(f"def {node.name}({args}){returns}:")
                doc = ast.get_docstring(node)
                if doc:
                    stub_lines.append(f'    """{doc}"""')
                stub_lines.append("    ...")
            elif isinstance(node, ast.ClassDef):
                stub_lines.append(f"class {node.name}:")
                stub_lines.append("    ...")

    return "\n".join(stub_lines)

if __name__ == "__main__":
    # 示例用法：扫描 src 目录并生成对应的 .stub.py 文件
    print("[apc] Stubs updated successfully.")
3. 受控读取工具 (smart_read.py)
禁用 Agent 的原生 read_file 工具，要求它只能通过 CLI 进行局部读取。

Python
# tools/smart_read.py
import argparse
import os

MAX_LINES = 100  # 物理硬性限制：单次最多读取 100 行

def main():
    parser = argparse.ArgumentParser(description="apc Protected File Reader")
    parser.add_argument("--file", required=True, help="文件路径")
    parser.add_argument("--lines", help="行数范围，例如 '10-50'")
    parser.add_argument("--symbol", help="查找特定函数或变量名")
    
    args = parser.parse_args()
    filepath = args.file

    if not os.path.exists(filepath):
        print(f"Error: File '{filepath}' not found.")
        return

    with open(filepath, "r", encoding="utf-8", errors="ignore") as f:
        lines = f.readlines()

    total_lines = len(lines)

    # 1. 未指定行数且文件过大时，抛出拦截错误
    if not args.lines and not args.symbol and total_lines > MAX_LINES:
        print(f"[apc REJECTED] File '{filepath}' has {total_lines} lines.")
        print(f"Error: Single-read limit exceeded ({MAX_LINES} lines max).")
        print("Please locate target lines using 'grep' first, then query with '--lines <start>-<end>'.")
        return

    # 2. 按行号切片输出
    if args.lines:
        try:
            start, end = map(int, args.lines.split("-"))
            if end - start > MAX_LINES:
                end = start + MAX_LINES
                print(f"[apc WARNING] Line range too large. Truncated to {MAX_LINES} lines.")
            selected = lines[max(0, start - 1):end]
            print("".join(selected))
        except Exception as e:
            print(f"Invalid line format: {e}")

if __name__ == "__main__":
    main()

② 记忆垃圾回收机制 (apc_gc.py)
设置阈值：当 apc.md 文件行数超出 150 行时，自动将状态为 [Resolved] 的历史调试记录移动至 archive/ 目录。

保持主 apc.md 占用 Token 始终维持在 1,000~2,000 Token 的极低区间。

5. apc.md 系统 Prompt 硬核规则（写入框架）
在 apc.md 的根规则中，将“道德建议”升级为命令协议：

Markdown
# apc Protocol v2.0 (Low-Token & Strict Isolation)

## 1. 视野限制 (Vision Isolation)
- 你的视角受 `.apcignore` 约束。源码与大文本文件已被屏蔽，你当前只能看到 `.stub` 结构文件与 `repo_map.json`。
- 严禁尝试全局调用 `read_file` 读取整份代码或日志文件。

## 2. 工具调用规范 (CLI Access)
- 若需要查看具体实现代码，**必须**按以下两步执行：
  1. 使用 `grep` 检索具体的关键词/函数名以定位行号。
  2. 调用 CLI 脚本：`python tools/smart_read.py --file <path> --lines <start>-<end>` 仅调阅局部 30 行内容。

## 3. 记忆自更新协议 (Self-Update)
- 禁止将大量代码块或日志原文直接追加至本文件。
- 更新记忆必须调用：`python tools/apc_update.py --section <section> --entry "<高密度单句摘要>"`。
